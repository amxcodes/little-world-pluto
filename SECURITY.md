# Security policy

Pluto is an early alpha and is not intended for high-risk environments. Keep Windows and provider tools up to date, and only configure MCP servers and speech endpoints that you trust.

Do not report vulnerabilities in a public issue. Once the repository is hosted, use GitHub's private vulnerability reporting if it is enabled; otherwise contact the maintainers through the private contact method on the project page. Include affected version/commit, impact, and a safe reproduction. Do not attach credentials, private prompts, personal files, or unredacted logs.

There is no guaranteed response time or supported release channel during alpha.
