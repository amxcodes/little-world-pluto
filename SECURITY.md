# Security policy

Pluto is an early alpha and is not intended for high-risk environments. Keep Windows and provider tools up to date, and only configure MCP servers and speech endpoints that you trust.

Do not report vulnerabilities in a public issue. Use GitHub's private vulnerability reporting when it is available for this repository; otherwise contact the maintainers through the private contact method listed on the repository page. Include the affected version or commit, impact, and a safe reproduction. Do not attach credentials, private prompts, personal files, or unredacted logs.

There is no guaranteed response time or support service level during alpha. When signed releases are published, they are distributed from the project's GitHub Releases page; availability and release cadence may change during alpha.
