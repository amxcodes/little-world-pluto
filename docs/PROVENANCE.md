# Implementation provenance

Some early shell motion tuning was informed by analysis of a third-party Windows application. The original application, extracted bundles, and analysis assets are not included in this repository. Product code and visual assets are implemented in this project.

Before a public alpha release, review the motion constants in `src/motion.rs` and any remaining implementation notes for licensing or terms-of-service concerns. This note is provenance context, not a legal determination.
