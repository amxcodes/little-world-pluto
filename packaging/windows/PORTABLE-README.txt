Littleworld Pluto portable build

Extract every file from this ZIP into one folder, then run Pluto.exe from that folder.
Keep the DLL files beside Pluto.exe. They provide the optional local Sherpa ONNX
wake-word engine. The wake-word model is downloaded on demand from Pluto's Voice
settings and is not included in this release bundle.
